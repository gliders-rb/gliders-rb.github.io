FieldStruct: typed POROs

Section titled “FieldStruct: typed POROs”

Declare typed fields on a plain Ruby class and you get an object that coerces what it is given and knows whether it is valid. There is no database in the picture, and no Rails.

The places count came in as a string and is an integer now. A blank name didn’t raise. It was recorded, and the message is waiting when you ask for it.

Actionable: service objects

Section titled “Actionable: service objects”

An action is a handful of plain methods, one per step, and every run ends in exactly one result: success, failure or skip. The input is a FieldStruct, so a step never sees bad input.

Above, the hero shows a success and two failures. The third outcome is a skip: the action had nothing to do, which is neither an error nor a success. A pottery studio’s kiln makes one.

Each result is a Success, a Failure or a Skipped, and each is a FieldStruct, so case ... in can branch on its class and its code in one line.

A skip stops the run like fail! does, so fire never runs for an empty kiln. Every declared code is plain data, so the branches read like the declarations.

Install

Section titled “Install”

Both gems go in your Gemfile. They are pre-releases for now, so the constraint names the pre-release version.

The second gem is actionable-rb because another project owns the short name, but you still require 'actionable'. Both need Ruby 3.3 or newer. This site documents field_struct 1.0.0.pre1 and actionable-rb 2.0.0.pre1, and CI executes every runnable example on it, the two above included, against those versions. A wrong # => comment fails the build.

Adapters

Section titled “Adapters”

A set of optional gems reads the same field metadata and writes other formats: JSON Schema, Avro, OpenTelemetry, Protobuf, plus actions exposed as LLM and MCP tools, and process pages for actions (Markdown with a Mermaid flowchart). Each is a prerelease, like the two gems. Start at the adapters overview, or jump to building your own adapter.

FieldStruct, Actionable and their adapters are open source under the MIT license.
